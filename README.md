# 💍 Wedding Day Reminders & Guest Planner

A modern, responsive, mobile-optimized Web App and PWA designed to manage every detail of the wedding celebrations, family guest lists, headcount RSVPs, and critical wedding milestones.

---

## 🌟 Key Features

### 1. ⏱️ Live Wedding Countdown & Details
- **Interactive Countdown**: Real-time ticker for both the **Main Wedding Day (Muhurtham)** and the **Night Before Celebration (Sangeet / Eve)**.
- **Venue & Timing Details**: Venue names, addresses, and Google Maps location quick access.
- **Customizable**: Edit couple names, dates, times, and venues anytime in the Settings menu.

### 2. 👥 Family Member Host Lists & Headcount Tracking
- **Categorized by Inviting Family Member**:
  - Filter and group guests by who invited them: *Groom (Rahul)*, *Bride (Anjali)*, *Father of Groom*, *Mother of Groom*, *Father of Bride*, *Mother of Bride*, or custom family hosts.
- **Separate RSVP Headcounts**:
  - **Wedding Day**: Confirmed total people / plates, pending estimates, and declined counts.
  - **Night Before the Wedding**: Confirmed total attendees for the eve celebration.
- **One-Click Quick RSVP**: Instantly mark (✓ Yes, ? Pending, ✗ No) and adjust total headcounts with stepper controls (`+` / `-`).
- **Direct WhatsApp Invitation**: One-click WhatsApp message button with personalized wedding details and RSVP link.
- **Export to CSV**: Download ready-to-share spreadsheets for caterers, wedding halls, and event coordinators.

### 3. 🔔 Crucial Special Reminders & Vendor Payment Tracker
- **Spotlight Milestones**:
  - 💍 **Order for Wedding Gold Chain / Mangalsutra & Rings** (Jeweler contact, hallmark verification, pickup dates).
  - 📸 **Payment for Camera & Cinematography Crew** (Advance paid, balance due tracking, deliverables).
  - 👗 **Wedding Attire / Suit & Saree Alterations Pickup**.
  - 🍽️ **Caterer Headcount Confirmation & Advance**.
  - 🪔 **Floral Garlands (Varmala) Delivery & Pooja Samagri**.
  - 💄 **Bridal Mehendi & Makeup Artist Call Times**.
  - 🚗 **Guest Transport & Hotel Rooms Allocation**.
- **Financial Tracker**:
  - Total Cost / Quotation vs. Advance Paid vs. Remaining Balance Due.
  - Visual payment progress bar for each vendor milestone.
  - Direct "Call Vendor" button to dial vendor phone numbers immediately from your phone.

### 4. 📅 Program Schedule & Ceremony Timelines
- Visual timeline for both the **Night Before Celebration** and **Wedding Day Muhurtham**.
- Auspicious muhurtham timings, feast/lunch schedules, dress code recommendations, and hall instructions.

### 5. ☁️ Realtime Cloud Sync & Family Collaboration
- **Zero-Setup Local Storage**: Works instantly offline on any phone or laptop.
- **Firebase Firestore Live Sync**: Enter a shared family room code and your free Firebase credentials to collaborate with family members in real-time.
- **Backup & Portability**: Export and import full JSON backups at any time.

---

## 🚀 Running the App

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

To access from your mobile phone on the same Wi-Fi network, use the network URL shown in your terminal (e.g. `http://192.168.x.x:3000`).

### Production Build
```bash
npm run build
npm run preview
```

---

## 📱 Installing on Mobile (iPhone & Android)
This app is built with PWA support:
- **iPhone / Safari**: Tap the **Share** button in Safari, then select **"Add to Home Screen"**.
- **Android / Chrome**: Tap the three dots menu, then select **"Install App"** or **"Add to Home screen"**.
